### 🪄 正在做的项目

#### 🌸 闪暖日活校准 · shining-nikki-daily

为《闪耀暖暖》日常任务制作的 Android 流程校准工具。通过悬浮窗逐步引导手动操作，记录流程纠错、截图点击坐标与分支路径，并导出 Markdown / JSON，为后续自动化准备流程数据。

**技术：** Java · Android · 无障碍服务  
**进度：** 测试版；当前以手动引导与校准为主，完整日常任务自动执行仍在规划中。

#### 🦾 NexArmSim · 机械臂虚拟仿真

用 React + Three.js 展示 NexArm 机械臂三维模型，支持关节角度、夹爪开合与末端虚拟相机视角；使用 Python + MuJoCo 验证方块下落和桌面碰撞。

**技术：** TypeScript · React · Three.js · Python · MuJoCo  
**进度：** 开发中；网页三维展示与物理测试目前分别运行，状态同步是后续目标。
